# ST-00.2 — Product Identity, Vision & Boundaries

**Project:** Syaahi
**Initiative:** phase_studio
**Microsprint:** ST-00.2
**Status:** Complete (documentation package)
**Baseline commit:** 13f6214 (tag v-ST-ST01)

## Purpose
This package establishes the product foundation for **Syaahi Studio** — an integrated
creative-writing environment within the existing Syaahi application. It builds directly
on the technical audit produced in `ST-00.1/` and translates it into an explicit product
identity, vision, feature classification, and boundary definition.

ST-00.2 is a **documentation-only** microsprint. No source code, schema, API, or
dependency was modified.

## Reading order
1. `PRODUCT_IDENTITY.md` — what Studio is and what it stands for
2. `PRODUCT_VISION.md` — long-term objective and creative journey
3. `PRODUCT_BOUNDARIES.md` — in scope / out of scope / ownership
4. `EXISTING_VS_PROPOSED_FEATURES.md` — classified feature inventory
5. `USER_JOURNEYS.md` — Android, desktop, draft, fragment, publish flows
6. `EXISTING_ARCHITECTURE_ASSESSMENT.md` — verified code-backed architecture
7. `RISKS_AND_CONSTRAINTS.md` — budget, compatibility, data, privacy
8. `DECISIONS_PENDING.md` — open questions requiring product-owner sign-off

## Source of truth
All product statements in this package are grounded in the inspected code and the
prior ST-00.1 audit. Where a capability is asserted as absent, the relevant code path
is cited (see `EXISTING_ARCHITECTURE_ASSESSMENT.md`).
