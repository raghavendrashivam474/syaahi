## Phase 1 — Core Writing Platform

**Goal:** User can register → write → publish → discover → read poems.

### Backend ✅ Done
- User registration / login / JWT
- Profile lookup + update
- Create / read / update / delete poems
- Rate limiting

### Frontend ⚪ Pending
- Splash, Welcome, Auth screens
- Home Feed
- Poem Writer + Reader
- Discover (by emotion)
- Profile

### Done When
End-to-end: open app → register → write → see in feed → read → view profile.

---

## Phase 2 — Archive System
Personal emotional timeline. Categories: Poems, Letters, Journals, Time Capsules.

## Phase 3 — Journals
Private writing with mood tagging, drafts, search. **Retention loop.**

## Phase 4 — Letters After Midnight
Anonymous letters. No usernames, no followers, no metrics.

## Phase 5 — Time Capsules
Future-delivered messages (1mo / 6mo / 1yr / custom).

## Phase 6 — Community Circles
Themed circles (Monsoon Poetry, Healing, Love Letters). No followers, no algorithmic feed.

## Phase 7 — Emotional Discovery
"How are you feeling today?" → matched poems.

## Phase 8 — Audio Poetry
Voice recordings, listening mode, background playback.

## Phase 9 — Analytics & Insights
Personal stats: streak, frequency, most common emotion, growth.

## Phase 10 — Launch Readiness
Rate limiting (✅), monitoring, error tracking, CI/CD, tests, backups.
